# Badminton Bracket

Session-based badminton matchmaking (Vite + Vue 3 + Tailwind). Data is saved in the browser (localStorage) until you start a new session or clear site data.

    npm install
    npm run dev       # local dev server
    npm run build     # production build in dist/

Deploys to GitHub Pages on every push to `main` (see .github/workflows/deploy.yml).
